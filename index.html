Drunk-Driving Prevention System

Personal project · Arduino Uno

An embedded safety system built around an Arduino Uno that keeps a vehicle from starting if the driver has been drinking — combining a breathalyzer-style sensor with seat-occupancy detection so the engine lock only engages when it matters.

  • Driver detection — an ultrasonic distance sensor continuously scans the driver's seat, so the system always knows whether someone is behind the wheel or the seat is empty.
  • Alcohol monitoring — a breathalyzer-style sensor constantly checks the driver's breath; crossing a pre-set safety threshold immediately triggers the emergency protocol.
  • Audio feedback — the buzzer gives a short beep whenever the driver sits down or leaves, and switches to a loud, continuous alarm the moment alcohol is detected.
  • Engine simulation — an LED stands in for the ignition: lit means the engine is unlocked and safe to start, and it cuts off the instant alcohol crosses the limit, simulating an automatic engine shut-off.
